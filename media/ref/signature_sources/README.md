# Подписи сотрудников Автосерт-М

Исходники извлечены из предоставленного пользователем `journal_С-00395.docx`:

- `specialist_original.png` — `word/media/image1.png`, специалист Женисов Бекзат Ерболатович.
- `lab_head_original.png` — `word/media/image2.png`, руководитель ИЛ и уполномоченное лицо Озықбай Береке Сембекұлы.

Очищенные файлы: `../specialist_sign.png` и `../lab_head_sign.png`.
Для очистки использован встроенный инструмент imagegen. Сохранены исходные
сканы для сверки: результат обработки изображения не является побитовой копией.

Запрос для подписи специалиста: убрать только серый фон бумаги и тени, заменить
фон на однородный белый (#FFFFFF); сохранить штрихи, петли, подчёркивание, наклон,
цвет чернил и пропорции исходной подписи; не добавлять новые элементы или текст.

Запрос для подписи руководителя: убрать только серую зернистость бумаги и шум
сканирования, заменить фон на однородный белый (#FFFFFF); сохранить штрихи,
петли, наклон, синий цвет чернил и пропорции исходной подписи; не добавлять новые
элементы или текст.

Обновление только имён и подписей сотрудников, без изменения печатей,
директора и подписей заказчиков:

```bash
python scripts/update_ref_documents.py --staff-only
```

Привязка изображений к должностям хранится в `STAFF_IMAGE_REPLACEMENTS`.
Размеры рисунков в DOCX подгоняются под существующее место без искажения
пропорций. Сами очищенные PNG встраиваются без повторной обработки.
